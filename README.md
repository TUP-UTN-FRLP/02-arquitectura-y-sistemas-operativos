# Arquitectura y Sistemas Operativos

**Tecnicatura Universitaria en Programación**

Material de la materia, organizado en dos bloques:

- **`MANUAL/`** — apuntes teóricos, una clase por archivo.
- **`PRACTICA_BASH/`** — trabajos prácticos de Bash; cada TP acompaña una clase del manual.

Todos los archivos están en UTF-8 (con BOM) y fin de línea LF.
